# 🔄 PROBLEM-SOLVING PROCESS

For **every problem**, follow this process:

1. Understand the problem
2. Identify input and output
3. Work through an example manually
4. Identify the required logic
5. Think of a brute-force solution
6. Write the steps in plain English
7. Write pseudocode
8. Convert it into Python
9. Test the solution
10. Check edge cases
11. Debug if necessary
12. Analyze time complexity
13. Analyze space complexity
14. Look for an optimized solution
