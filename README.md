# **How to Solve a Coding Problem**

## **Understanding a Problem**

### **Read the problem carefully**

- **Step-1:** *Read the problem carefully*

  *Before writing Python code understand what the Problem is asking you to do.*

  **Example-1:** 

  **Problem:** *Given an integer ```n```, determine whether it is even or odd*

  - **Input:** *```n = 7```*
  - **Output:** *```Odd```*

---

### **Identify the input**

*The input is the number ```n``` whose value is ```7```*

---

### **Identify the expected output**

*We must determine whether the number is even or odd*

---

### **Understand the constraints**

- **Even:** *Divisible by 2 with no remainder*
- **Odd:** *Not divisible by 2 with no remainder*

*For ```n = 7``` the remainder when divided by 2 is 1 so the answer is ```Odd```*

---

- **Step-2:** *Identify the constraints*

*Constraints are the rules or limits that tell us what inputs a problem allows.*

*For example ```Given an integer ```n``` determine whether it is even or odd. The constraint is ```1 ≤ n ≤ 1000```*

- *```1 ≤ n``` means n is greater than or equal to 1*
- *```n ≤ 1000``` means n is less than or equal to 1000*

*This tells us that ```n``` can be any integer from 1 through 1000, including both endpoints.*

---

### **Identify exactly what's being asked**

*Sometimes a question gives you numbers but asks for a specific result. You must identify the requested operation.*

*Consider these three questions using the same input ```n = 6```*

| Problem asks you to...         | Expected output |
| ------------------------------ | --------------- |
| Find the square of `n`         | 36              |
| Count integers from `1` to `n` | 6               |
| Find the sum from `1` to `n`   | 21              |

*The input is the same, but the expected outputs differ becuase the tasks differ.*

---

## **Breaking down the Problem**

### **Solve the problem manually**

*Given a list of numbers, find the largest number*

**Example:**

```txt
Input: [4, 9, 2, 7, 5]

Output: 9
```

- **Step-1:** *Look at the first number ```4```*
- **Step-2:** *Compare it with ```9``` The larger number is ```9```*
- **Step-3:** *Compare ```9``` with ```2``` Keep ```9```*
- **Step-4:** *Compare ```9``` with ```7``` Keep ```9```*
- **Step-5:** *Compare ```9``` with ```5``` Keep ```9```*

*The largest number is ```9```*
